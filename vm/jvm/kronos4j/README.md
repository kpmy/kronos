# Эмулятор КРОНОС

Java-вариант интерпретации инструкций команд процессора и эмуляция IO-подсистемы 

## Запуск

```shell
mvn package

java -jar .\target\kronos4j-jar-with-dependencies.jar 
```
Вход под юзером `su`.

Диски перечислены в application.properties относительно данного репозитория в папке `disks`.

```text
../../../disks/xd0.dsk,../../../disks/xd1.dsk
```
